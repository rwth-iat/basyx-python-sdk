# Access Control for the Eclipse BaSyx Python SDK - HTTP Servers

This folder describes the access-control concept for the [BaSyx Python SDK HTTP servers](../server/README.md). The main advantage of this approach is that it is not limited to the BaSyx Python SDK servers: it can also be used with other HTTP servers or applications.

The general concept is described in [`examples/general`](examples/general).

A proof of concept using the BaSyx Python SDK servers together with the [BaSyx AAS Web UI](https://github.com/eclipse-basyx/basyx-aas-web-ui) is provided in [`examples/basyx`](examples/basyx).
